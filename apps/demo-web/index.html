실제 앱 화면

실제 제품은 매장 PC 에 설치하는 데스크톱 앱입니다. 카메라와 같은 공유기에 있어야 영상을 받을 수 있어 브라우저로는 만들 수 없는 부분이라, 이 체험판에서는 같은 화면을 가짜 카메라로 돌립니다.

  2. 2 감시 시작

    • 3 위험 감지 → 알림

      영상이 흐르다 이상 행동이 잡히면 PC 화면에 경고가 뜨고, 같은 순간 휴대폰으로 알림이 갑니다. 기다리시면 저절로 울립니다. 지금 바로 보시려면 아래 버튼을 누르세요.

    이 체험판에서 진짜인 것과 아닌 것

    진짜: PC 앱과 모바일 앱 화면 그대로, 영상 조각을 나누고 올리는 흐름, 그리고 휴대폰으로 가는 알림(웹 푸시 표준).

    흉내: "이 구간이 위험하다"는 AI 판정과 서버 응답. 실제 서비스에서는 영상 분석 서버가 맡는 부분입니다.

    실제 제품과 다른 점: 매장 PC 앱은 카메라와 같은 공유기에 있어야 영상을 받을 수 있어 데스크톱 앱으로 만듭니다. 여기서는 같은 화면을 브라우저에서 가짜 카메라로 돌립니다.

    실제 제품은 매장 PC용 데스크톱 앱과 사장님용 모바일 앱입니다. 이 페이지는 심사·체험을 위한 웹 버전입니다.
