영상 속 이상 행동이 조각으로 올라가 서버 AI 판정을 거쳐 경고가 되기까지 1~2분 걸립니다. 경고와 휴대폰 알림은 AI 가 위험으로 판정했을 때만 옵니다.

    휴대폰 카메라로 찍으면 사장님 앱이 같은 데모 계정으로 열립니다. 페이지를 열어 둔 채로 두면 서버 AI 가 위험을 판정할 때 휴대폰에도 바로 뜨고, 알림 받기를 눌러 두면 휴대폰 알림으로도 옵니다.

    아이폰에서 알림까지 받으려면 사파리 공유 버튼 → '홈 화면에 추가' 한 앱에서 열어 주세요.

    실서버 시연을 시작하지 못했습니다

      Vercel 프로젝트 Settings → Environment Variables 에 위 값을 넣고 다시 배포하면 됩니다. 자세한 절차는 저장소의 docs/demo-submission.md 에 있습니다.

      씬스틸러

      이 주소는 매장 PC 에 설치하는 수집기 화면이라 넓은 화면이 필요합니다. 휴대폰에서는 사장님 앱을 바로 열어 보세요.

      사장님 앱 열기

      전체 흐름(시연 영상 → 서버 AI 판정 → 경고·알림)은 노트북에서 이 주소를 열면 보실 수 있습니다.
