`feat/scene-stealer-pc-redesign` 기준. 디자인 출처는 `design/씬스틸러 PC 앱.dc.html`(화면)과

## 0. 위험 종류 분류를 하지 않는다 (2026-09-17 결정)

디자인은 AI 가 위험 종류(절도·배회·쓰러짐 …)를 판정하고 한글 설명·인상착의를 준다는 전제로
그려져 있다. **최종적으로 종류 분류는 빼기로 했고, AI 는 지금 파이프라인 그대로다** — 평소와 다른
움직임 구간과 이상 점수만 준다. 위험도(높음·보통·낮음)는 그 점수로 정한다 (docs/api-contract.md 7절).

| 화면 | 디자인 | 구현 |
|---|---|---|
| 2c 피드 · 2d 제목 · 2e 표 · 2f 제목 | `절도 의심`, `장시간 배회` … | `이상 행동` 하나 + 위험도 태그 |
| 2c 피드 | 높음 카드에 한 줄 설명 | 없음 |
| 2d · 2f | `AI 설명` 칸, 클립 위 인물 박스 | 없음 |
| 2e | `종류` 필터 · 내용 칸 `절도 의심 · 설명` | `위험도` 필터 · `이상 행동 · 31초` (지속 시간) |
| 2g | 위험 종류 7줄 (켬/끔 · 민감도 · 쓰러짐 잠금) | `알림 받을 위험도` 한 줄 — 낮음 이상 / 보통 이상 / 높음만 |
| 2g | 수면 시간 `응급·높음만 소리로` | `높음만 소리로` |
| 2d · 2f 112 안내문 | 상황 설명 · 인상착의 | `상황: CCTV 이상 행동 감지 (위험도 높음)` |
| 2b | 위치 태그 `— AI 판단에 사용` | 보조 설명 없음 (지금 AI 는 위치 태그를 쓰지 않는다) |

바꾼 화면(2c·2d·2e·2f·2g)은 목업 빌드를 오프스크린 Electron 창에 띄워 다시 캡처해 봤고, 2g 에서
'보통 이상'을 눌러 저장되고 다른 칸에 갔다 와도 유지되는 것까지 확인했다.

## 2. 디자인에 없던 상태를 고른 것

값은 전부 디자인시스템 팔레트 안에서 골랐고, 코드에 이유를 한 줄씩 남겼다.

- **버튼 hover/active** — 같은 색 계열의 다음 단계(blue/700·800, error/700·800, gray/50·100).
  navy(`#14233D`)는 더 어두운 단계가 없어 밝기로 표현했다.
- **disabled** — 디자인의 `loading = gray/300` 과 같은 모양. 둘 다 "지금 누를 수 없다"는 뜻이다.
- **'서버 연결 끊김' 배너** — error/50 바탕 + error/main 글자 (위험 카드 배경과 같은 계열).
- **매장 선택 칩 드롭다운** — 카드 반경 + modal 그림자.
- **2e 표의 '미확인' 태그** — 디자인대로 빨간 계열. 디자인시스템 샘플의 파란 '미확인'과 다르다.

## 3. 실제로 동작을 바꾼 것 (디자인 밖)

- **2d 팝업은 위험도 '높음'에만 뜬다.** 보통·낮음은 피드와 배지로 쌓인다.
  계산대 PC 앞에서 사소한 움직임마다 창이 튀어나오면 사장님이 알림을 무시하게 된다.
  2g 'PC 팝업 + 소리'로 끌 수 있다.
- **기본 알림 빠르기(조각 길이) 5분 → 1분.** 디자인 2b 의 기본값이자 백엔드 기본값.
  이미 설치된 PC 의 저장값은 바뀌지 않는다.
- **2d 경보음은 음원 파일 없이 WebAudio 로 만든다.**

## 4. 디자인과 나란히 비교

위험 종류 분류를 빼기 전(2026-09-17 오전)에 한 비교다. 그 뒤 바뀐 자리는 0절에 있다.

**방법.** 오프스크린 Electron 창(1440×900)에 디자인 `.dc.html` 의 2a–2g 화면과, 같은 크기로 띄운
렌더러(미리보기 mock 데이터)를 각각 캡처해 좌우로 붙여 봤다. 렌더러만 띄운 것이라 메인 프로세스
(카메라·ffmpeg·IPC)는 거치지 않았다.

**비교에서 찾아 고친 것.**

| 증상 | 원인 | 고친 곳 |
|---|---|---|
| primary 버튼(`확인했어요`·`확인`·`감시 시작`) 글자가 남색 바탕에 안 보임, 곳곳의 글자 크기가 기본값으로 돌아감, 끊긴 카메라 카드의 빨간 테두리가 안 보임 | tailwind-merge 가 토큰 이름(`text-body`, `shadow-card` …)을 몰라 '색'으로 보고 앞 클래스를 지웠다 | `lib/cn.ts` 에 토큰 이름 등록 + `tests/unit/cn.test.ts` |

**비교해도 다른 것 (그대로 둠).**

- 2a 카드 위치가 디자인보다 아래 — QR 줄을 빼서(1절) 카드가 낮아졌고, 세로 가운데 정렬이다.
- 2c 격자 두 행 높이가 같음 — 디자인은 행 높이 지정이 없어 내용 따라 1행이 조금 낮게 그려졌다.
- 2b `확인` 버튼이 입력 칸과 같은 48px — 디자인은 `height:48px` 에 padding 이 더해져(content-box) 68px 로 그려졌다.
- 매장 이름·사용자·숫자·시각은 mock 데이터 차이.

**영상이 있는 상태는 비교하지 못했다.** mock 에는 실제 영상이 없어 2d 플레이어 조작 막대,
2f '같은 시각 다른 카메라' 썸네일은 '영상 없음' 상태로만 봤다. → 2026-09-19 에 웹 데모 빌드로 봤다 (아래).
