# 데모가 최종적으로 가야 할 곳

2026-09-18 결정. 심사위원이 웹에서 체험하되, **흐름은 실제 서비스 그대로** 돌린다.

## 목표 흐름

```
특별 URL 로 접속
   ↓
그 URL 에 묶인 특정 계정으로 자동 로그인 (PC · 모바일 둘 다)
   ↓
데모 영상을 CCTV 인 척 연결하는 플로우
   ↓
5분 단위로 잘라 실제 서버로 전송
   ↓
백엔드에서 AI 가 분석
   ↓
AI 가 위험으로 판단하면 → 그 계정의 모바일로 푸시 알림
```

핵심은 **AI 판정이 진짜여야 한다**는 것이다. 지금 데모는 "이 구간이 위험하다"를 화면이
지어내지만, 목표 구조에서는 백엔드의 AI 워커가 실제로 판단한 결과만 알림이 된다.

## 지금과 무엇이 다른가

| | 지금 (`feat/web-demo` → main) | 목표 |
|---|---|---|
| 로그인 | 데모 모드가 가짜 세션을 끼움 | 특별 URL 의 토큰으로 **실제 계정** 로그인 |
| 데이터 | 브라우저 안의 가짜 서버 | **배포된 백엔드** |
| 영상 수집 | 화면이 재생만 함 | 데모 영상을 RTSP 로 물려 **실제로 5분씩 잘라 업로드** |
| 위험 판정 | 화면이 정해진 시각에 지어냄 | **AI 워커의 실제 판정** |
| 푸시 | 데스크톱이 직접 발송 | 백엔드가 AI 결과를 보고 발송 |

## 미해결 — 가장 큰 구멍

**웹 브라우저는 RTSP 를 못 연다.** "데모 영상을 CCTV 인 척 물려 5분씩 잘라 올린다"는
데스크톱 앱이 하는 일이고, 그래서 이 제품이 Electron 인 것이다. 심사위원이 브라우저만
여는 상황에서 이 구간을 어떻게 진짜로 돌릴지는 아직 답이 없다. 후보는 셋이다.

1. **서버 쪽에서 돌린다** — 데모 계정에 붙은 수집기를 우리 서버에서 상시 가동해 놓고,
   심사위원은 그 결과를 보기만 한다. 업로드·분석·푸시는 전부 진짜다.
   대신 "심사위원이 영상을 넣는" 조작감은 없다.
2. **심사위원이 데스크톱 앱을 깐다** — 규정상 설치 파일 직접 배포가 금지라 불가.
3. **지금처럼 화면만 흉내** — 가장 안전하지만 AI 판정이 진짜가 아니다.

1번이 유력하다. 목표 흐름의 "실제 AI 판정 → 실제 푸시"를 지키면서 브라우저 제약도 피한다.

### 1번을 고를 때 알아야 할 것

**"서버를 켠다" 와 "수집기를 돌린다" 는 다른 일이다.** 상시 떠 있어야 하는 프로세스가 넷이 된다.

| 프로세스 | 하는 일 |
|---|---|
| 백엔드 API | 조각 받고, 이벤트 만들고, 푸시 보냄 |
| AI 워커 | 조각을 분석해 위험 구간 판정 |
| 가짜 카메라 | 데모 영상을 RTSP 로 계속 뱉음 |
| 수집기 | 그 RTSP 를 받아 잘라서 API 로 올림 |

아래 둘은 원래 **매장 PC 가 하는 일**이라 "서버 배포" 에 안 들어간다. 웹 데모에는 매장 PC 가
없으니 우리 서버가 대신 진다.

**다행히 수집 코드는 Electron 에 묶여 있지 않다.** 확인해 보니 `fleet.ts` · `camera-worker.ts` ·
`uploader.ts` · `segment-recorder.ts` · `spool-store.ts` 모두 `from 'electron'` 이 0건이다.
Electron 을 쓰는 건 `src/main/index.ts`(앱 창) · `ipc.ts`(화면 다리) · `services/token-store.ts`
(비밀번호 저장) 셋뿐이고 전부 껍데기다. **작은 Node 진입점 하나만 쓰면 창 없이 서버에서 돌릴 수 있다** —
로직을 새로 짤 필요가 없다. `token-store` 만 환경변수를 읽는 것으로 바꾸면 된다.

따져야 할 것 셋:

- **한 달 내내 돈다** (9/21~10/17). 영상 인코딩과 업로드가 계속이라 CPU·트래픽이 실제로 든다.
  짧은 영상을 낮은 비트레이트로 돌리면 싸게 막힌다.
- **조각 길이를 30초로.** 5분이면 심사위원이 이벤트 하나 보려고 5분을 기다린다.
  앱에 이미 30초 선택지가 있다.
- **심사위원이 영상을 직접 넣는 조작감은 사라진다.** 이미 돌고 있는 걸 보는 형태가 된다.
  이걸 받아들일 수 있느냐가 이 방향의 갈림길이다. 대신 얻는 건 AI 판정이 진짜가 되는 것.
