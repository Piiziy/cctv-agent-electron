# 시연 영상

`/wanted-test` 실서버 시연에서 **CCTV 대신 쓰는 영상**을 여기에 넣는다. 영상 하나가 카메라 한 대다.

```
public/demo-video/01-계산대.mp4   → 카메라 이름 '계산대'
public/demo-video/02-출입문.mp4   → 카메라 이름 '출입문'
```

- 앞의 번호는 순서만 정하고 이름에서는 빠진다. **파일 이름을 바꾸면 서버에서 다른 카메라가 된다**
  (카메라 id 가 파일 이름에서 나온다).
- mp4 · mov · m4v · mkv · webm · avi 를 받는다.
- 넣고 `main` 에 올리면 Vercel 빌드가 알아서 자른다. 손으로 할 일은 없다.

## 빌드가 하는 일

`apps/demo-web/scripts/demo-video.mjs` 가 매장 PC 에이전트와 같은 모양으로 미리 잘라 둔다.

| | 기본값 | 바꾸려면 |
|---|---|---|
| 조각 길이 | 30초 | `DEMO_SEGMENT_SECONDS` (30 · 60 · 300 중 하나 — 매장 설정 값과 같아야 한다) |
| 화질 | 세로 480 (원본보다 키우지 않음) | `DEMO_VIDEO_HEIGHT` |
| 초당 프레임 | 15 | `DEMO_VIDEO_FPS` |
| 소리 | 뺀다 | — |

화질·프레임을 낮춘 이유: 서버 AI 는 **프레임마다** 사람 자세를 뽑는다. 30fps 원본을 그대로 올리면
CPU 서버에서 30초 조각 분석이 30초를 넘겨 대기열이 밀린다. 흔한 CCTV 보조 스트림(480p · 15fps)과 같게 맞췄다.

로컬에서 미리 잘라 보기:

```bash
node apps/demo-web/scripts/demo-video.mjs
```

## 영상 고를 때

서버 AI 는 **조각 하나 안에서** 유독 튀는 움직임을 위험으로 본다 (조각마다 따로 학습한다).

- 이상 행동은 30초 조각 안에서 **짧게** 일어나야 잡힌다. 조각 대부분이 이상 행동이면 그게 '보통'으로 학습된다.
- 조각 경계(30초 · 60초 …)에 걸치지 않게 두는 게 좋다.
- 올리기 전에 서버에서 한 번 돌려 보고 위험도가 '높음'으로 나오는지 확인한다 — PC 경고창은 '높음'에만 뜬다.
- 영상 파일은 배포에 그대로 실려 **누구나 받을 수 있다**. 공개해도 되는 영상만 넣는다.
